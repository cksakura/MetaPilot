COMPLETE WORKFLOW FEATURES:
===========================
• MULTI-ENGINE SUPPORT: pFind, Sage, FragPipe
• MAG DATABASE INTEGRATION: HAP FASTA files for high abundant proteins
• TWO-STAGE SEARCH: HAP search → Sample-specific database search
• SPECTRA CONVERSION: Raw files → .mgf/.mzML/.pf2 formats
• DUAL OCCAM'S RAZOR: Genome-level + Protein-level filtering
• PROGRESS TRACKING: Real-time progress updates via secondBar
• COMPREHENSIVE REPORTS: TSV + HTML formats with detailed statistics
• TAXONOMIC ANALYSIS: Full taxonomic rank aggregation (superkingdom → species)
• FUNCTIONAL ANNOTATION: Rich functional data from MAG database

SEARCH ENGINE DIFFERENCES:
==========================
• pFind: Direct .mgf/.pf2 conversion, single conversion step
• Sage/FragPipe: .mzML conversion → .mgf conversion, two-step process

MAG-SPECIFIC FEATURES:
=====================
• HAP SEARCH: High Abundant Protein database search first
• PROTEIN EXTRACTION: Extract sequences from HAP results
• SAMPLE-SPECIFIC DATABASES: Create individual databases per sample
• GENOME-LEVEL FILTERING: Occam's razor at genome level
• MAG DATABASE INTEGRATION: Rich taxonomic and functional data

API INTEGRATION:
===============
• MagFuncSearcher: Functional annotation from MAG database
• TaxonomyDatabaseSQL: Taxonomic lineage resolution
• MetaProteinXMLWriter/Reader: XML-based functional data processing

OCCAM'S RAZOR FILTERING:
=======================
1. Genome-Level: Select best genomes based on protein evidence
2. Protein-Level: Select best proteins based on peptide evidence
3. Final Filtering: Apply FDR threshold and remove low-confidence hits

PROGRESS TRACKING:
=================
• 0-5%: Initialization and report template copying
• 5-10%: Spectra conversion (varies by search engine)
• 10-20%: High abundant protein search
• 20-40%: Protein extraction from HAP results
• 40-65%: Sample-specific database search
• 65-70%: Result combination
• 70-85%: Quantification (label-free or isobaric)
• 85-100%: Report generation and analysis

KEY DIFFERENCES FROM IGC WORKFLOW:
==================================
• HAP SEARCH: Additional high abundant protein search step
• PROTEIN EXTRACTION: Extract sequences from HAP results
• GENOME-LEVEL FILTERING: Additional genome-level Occam's razor
• MAG DATABASE: Rich functional and taxonomic data from MAG database
• SAMPLE-SPECIFIC DATABASES: Individual databases per sample vs. single database
