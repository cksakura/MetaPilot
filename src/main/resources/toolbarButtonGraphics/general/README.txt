Please place the Open16.gif icon file in this directory.

The icon should be a 16x16 pixel GIF file named "Open16.gif".

If you don't have the icon file, you can:
1. Use any 16x16 GIF icon file and rename it to Open16.gif
2. Create a new 16x16 GIF icon file
3. Download a suitable icon from a free icon website

The application will work without the icon, but it will show only text for the "Load Parameters" button.
