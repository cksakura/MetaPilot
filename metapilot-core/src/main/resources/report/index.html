💡 Working with MetaPilot Reports

How reports are generated

  1. MetaPilot workflows compile TSV outputs for taxonomy, proteins, peptides, IDs, and functional analysis.
  2. The Python report engine renders interactive Plotly figures and writes HTML files to report/reports/.
  3. Each export refreshes the report files, which can then be accessed directly from this page.

Tips

  • Reports open in a new tab with Plotly zoom, filter, and export tools enabled.
  • Regenerate analyses to refresh the reports—older versions of a report are replaced automatically.
  • HTML files are self-contained, so you can share them directly with collaborators.
