COMPLETE WORKFLOW FEATURES:
===========================
• MULTI-ENGINE SUPPORT: pFind, Sage, FragPipe, MaxQuant
• SPECTRA CONVERSION: Raw files → .mgf/.mzML/.pf2 formats
• DATABASE REDUCTION: Sample-specific database generation
• BATCHED API CALLS: Prevents HTTP 500 errors with large datasets
• TWO-STAGE FILTERING: Protein-level + Species-level Occam's Razor
• PROGRESS TRACKING: Real-time progress updates via secondBar
• COMPREHENSIVE REPORTS: TSV + HTML formats with detailed statistics
• TAXONOMIC ANALYSIS: Full taxonomic rank aggregation (superkingdom → species)
• FUNCTIONAL ANNOTATION: EC numbers and GO terms from UnipProInfo

SEARCH ENGINE DIFFERENCES:
==========================
• pFind: Direct .mgf/.pf2 conversion, single conversion step
• Sage/FragPipe: .mzML conversion → .mgf conversion, two-step process
• MaxQuant: Integrated workflow with built-in conversion

API INTEGRATION:
===============
• Unipept pept2prot API: Peptide → Protein mapping (BATCHED)
• Unipept protinfo API: Protein → Taxonomic/Functional info (BATCHED)
• TaxonomyDatabaseSQL: Taxonomic lineage resolution

OCCAM'S RAZOR FILTERING:
=======================
1. Protein-Level: Select best proteins based on peptide evidence
2. Species-Level: Select best species based on protein evidence
3. Final Filtering: Apply FDR threshold and remove low-confidence hits

PROGRESS TRACKING:

• 25-50%: Database reduction
