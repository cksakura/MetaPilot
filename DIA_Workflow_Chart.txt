DIA DATA ANALYSIS WORKFLOW - MetaDiaTask.java
=======================================================

OVERVIEW
--------
DIA (Data-Independent Acquisition) workflow for metaproteomics analysis using DiaNN.
Extends MetaPilotMagTask and provides three analysis modes:
- Library Search Mode (using existing spectral libraries)
- Self Model Search Mode (using self-generated models)  
- Iterative Search Mode (iterative library building and searching)

DETAILED WORKFLOW BRANCHES
═══════════════════════════════════════════════════════════

LIBRARY SEARCH MODE:
├─ Use pre-existing spectral libraries
├─ Skip iterative library building
├─ Direct identification with DiaNN
└─ Faster processing, requires quality libraries

SELF MODEL SEARCH MODE:
├─ Use pre-built self-generated models
├─ Skip library building phase
├─ Direct identification with models
└─ Balanced speed and accuracy

ITERATIVE SEARCH MODE:
├─ Build sample-specific libraries iteratively
├─ Multiple rounds of identification and refinement
├─ Highest accuracy but slower processing
└─ Best for novel or poorly characterized samples

WORKFLOW COMPARISON
═══════════════════════════════════════════════════════════

DIA vs DDA MAG:
├─ DIA: Library-based identification, higher throughput
├─ DDA MAG: Spectrum-based identification, higher specificity
├─ DIA: Better quantitative reproducibility
├─ DDA MAG: Better identification depth for novel proteins

DIA vs IGC:
├─ DIA: Genome-based taxonomy, MAG database integration
├─ IGC: Protein-based taxonomy, Unipept integration
├─ DIA: Comprehensive functional annotation
├─ IGC: Simplified functional annotation
